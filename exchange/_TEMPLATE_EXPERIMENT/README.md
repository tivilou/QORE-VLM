### `<趟次>` 为什么作废

**废的趟次一定要写清为什么废，而且比写结论更重要。**
后一趟往往是前一趟的修正，三个月后回来看，没这段就不知道该读哪个、
也不知道当初那个坑还在不在。

---

## 命名

`<YYYYMMDD>T<HHMMSS>`，**北京时间**，取**第一个实验的开始时刻**。

```bash
date +%Y%m%dT%H%M%S      # 不加 -u，我们用北京时间
```

同一天跑几趟就自然按时间排开，不用 `_a` / `_b`。

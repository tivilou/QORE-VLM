# Local Born：师弟完整 smallset 实验

更新到包含本文件的 GitHub 提交后，在 Linux GPU 服务器的项目根目录执行：

```bash
bash scripts/run_local_born_smallset.sh
```

已有私有 `~/.config/qduet/junior.json` 会自动复用。首次缺少配置时，入口只询问服务地址和隐藏输入的令牌；不要求手填数据或模型路径。配置和令牌不要提交到 GitHub。入口自动获取并校验既有 **TriviaQA 8000 train／1000 valid／1000 test** 输入、二分类运营标签和原模型文件，准备环境、训练、封存预测、评估并上传声明结果。它不会执行旧的393项或54项方案。

训练中断后：

```bash
bash scripts/run_local_born_smallset.sh --resume
```

只观察、不启动任务：

```bash
bash scripts/run_local_born_smallset.sh --watch
```

`--plan-only` 无下载、无训练；`--prepare-only` 只准备并核验资产；上传失败后用 `--upload-only` 重传已封存结果。默认工作目录为 `~/qduet-local-born-smallset`，可用 `--workspace` 指定其他服务器磁盘。图形进度包含阶段、固定任务清单、worker/父进程心跳、CPU进程组内存、GPU显存、训练步及已提交检查点；整套ETA在缺少可比实测时保持待测。

## 实验构成

两骨干分别保留原生 DPR Reader multiset、BGE reranker v2-m3 的输入、原权重和最后层FFN输出投影／残差／LayerNorm；BGE保留原dense+tanh。训练只使用train。每个臂联合优化两骨干的当前线性头及该臂的机制参数，两模型的机制参数块分开；这不是已经证明的跨模型权重迁移。

| 臂 | 用途 |
|---|---|
| NATIVE（各模型一次） | 冻结原始评分 |
| HEAD | 只适配原线性评分头 |
| QUANTUM | 固定原生输出模态坐标中的局域旋转与Born平方读出 |
| SIGNED_LOCAL | 同旋转，保留有符号值 |
| GELU_LOCAL | 同旋转，经典GELU读出 |
| ABS_LOCAL | 同旋转，绝对值读出 |
| DEPHASED | 同旋转，删除固定输入基中的相干交叉项 |
| RANDOM_FRAME | 同局域Born机制，配对随机坐标方向 |
| CLASSICAL_MATCHING | 既定随机配对经典替代 |
| MLP8 | 既定8隐单元经典替代，参数量差异保留披露 |

9个学习臂 × 3种子（20261122、20261123、20261124）=27个双模型训练任务；加上两个原生评分组，最终为 **56组预测**。每组包含各自完整valid与test，每题50个分数、固定原索引并列规则，选Top5。共同20轮、逻辑batch8、AdamW lr0.001／weight_decay0／clip1，最终检查点，不按test选轮次或模型。8000训练题时每任务20000步。所有失败和负种子都应保留。

机制：对原生冻结输出矩阵取完整行空间基V，令 y=Vᵀz；DPR的768维补零至1024，BGE使用1024维。局域U是10个单比特RY的张量积，20个名义角度／10个有效角度。以 r=||y||/sqrt(1024)，Aθ=|Uθy|²/r−r，用 `GELU(z)+V(Aθ−A初始化)` 替换最后FFN的激活输入，原生后续层不变。零路径与初始冻结参考保持一致。实际V、原生尾部参数和初始化在声明元数据／检查点中保留；不能仅凭重做SVD声称字节相同。

## 已有证据与本轮目的

现有结果只来自固定80训练／20反复曝光留出题。三种子的useful总数（每种子分母100）为：

| 模型 | 原生，每种子 | HEAD | QUANTUM | 最强声明经典／删除对照合计 |
|---|---|---|---|---|
| DPR | 81 | 87／88／87 | 87／88／88 | 262／300 |
| BGE | 83 | 83／83／82 | 83／84／83 | 249／300 |

QUANTUM合计DPR263／300、BGE250／300，仅各超过最强声明对照1个useful位置。这支持**固定adaptive toy范围内的受控L3**，没有统计确认或独立泛化证明；不是每个seed都胜。全纠缠旧146方案的负结果仍保留。局域Born可精确经典模拟；无硬件加速、量子专属性、新基本原语或纠缠必要性结论。完整smallset结果尚待师弟实际运行。

## 存储、环境与恢复

推荐Linux、可用CUDA GPU、至少32GiB内存，首次提取前至少40GiB空闲磁盘。按题保存FP32 FFN输入／残差／特征，两个模型10000题的原生数值主体约22GiB，另加模型、缓存元数据、检查点和结果；不保存全序列张量，不需要1.5TB缓存。CPU工作缓存上限512MiB，只将当前8题送入GPU；尚未承诺特定GPU上的吞吐。后续至少保留8GiB空闲，扩盘后可续跑。

复用兼容环境，或自动建立私有venv，固定Torch2.13.0、Transformers4.44.2、tokenizers0.19.1。保持FP32原生尾部、FP64机制、禁用TF32和确定性策略，不静默切换精度或attention实现。来源闭包、输入与角色SHA、完整模型及优化器状态、初始化参考、RNG及梯度活动均绑定；已完成任务直接校验并跳过。版本或输入变化应使用新工作目录。

资产准备阶段会校验并整理valid/test标签文件，也会计算发布数据的可提升上限；训练与预测子进程不使用这些评价标签。全部56组预测先共同封存，之后才按身份连接标签计算最终指标。完整50候选标签的二分类useful不等于人工语义金标准。结果和最终完整检查点、实际坐标与尾部元数据通过已有私有服务回传；token、题文、标签不进入GitHub。运行中的恢复点目前为服务器本地状态，未宣称已部署跨机定期云备份。请保留服务器工作目录直至回传收据核验完成。

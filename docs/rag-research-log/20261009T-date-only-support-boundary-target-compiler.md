# 支持资格感知边界目标：先把“教模型纠什么错”说清楚

时间精度：仅记录2026-10-09日期。这是已完成的离线工程检查点，不是训练结果。

## 通俗解释：研究主线和本次改变

本研究固定每题召回的50个段落，只优化从中选5个。DPR Reader给出原始
相关分，我们保留它作为锚点；量子语义头读取Reader内部的问题条件表示，
学习小幅、可控的分数修正。此前用“段落含答案字符串”教这个头，发现有
真正支持答案的段落被当负例，也有只有关键词的段落被当正例。优化器修复
后虽有分数修正，仍可能只是非选择性压缩分数，而非识别证据。

此次新增的是离线目标编译器，不是新的线路，也没有接入旧训练损失。
它把已经审阅过的段落记录与另存的独立资格记录连接起来：只有问题范围
和段落判断都得到资格核验，才能提出“漏选正确段应高于已选无关段”的
训练草案；先保护Reader已经选对的段，不把有帮助但不完整的段强判成错。
真实数据的资格记录目前全部pending，编译后仍关闭训练。

完整数据和判断元数据，独立见证文件需重新打开核对哈希；这些检查只能
证明记录一致，不能替代独立审阅或自动证明标注正确。

## 累积经验与解释

[已测事实] 原Answer Scorer是目前稳定锚点；固定span融合、去冗余/集合
干预未稳定胜过它。修复语义头的优化路径后，没有获得支持特异性收益。
完整审计发现32个direct弱负例和58个irrelevant弱正例，但仅限这32题。

[机制解释] 不能再只问“量子表达更强吗”。先确认监督真的奖励正确支持，
并区分可替无关段、仍有用partial、问题自身范围不清和已有5个好段。
28个候选对的10槽位预算，比笼统说25个缺口更接近本机制实际要修的错。

[尚未证明] 干净边界监督是否让量子头胜过同预算经典头、是否推广到新题、
是否有理想量子资源优势，均未验证。此编译器是经典 bookkeeping，非量子
优势证据；保留主线不等于先宣称它有效。

## 唯一推荐下一步

先独立核验9题范围及direct/irrelevant/已有direct保护见证，形成真实的资格
覆盖层；再扩至完整434监督与新347/87预注册，才设计并接入受保护的量子
边界损失。最小下一步是9题已有文本审阅，不下载数据、不跑训练，CPU/I/O
很轻；时间主要花在语义核验。

成功门：问题的时间/地点/版本/实体/指标/参考关系逐项说清，段落判断有
独立见证，部分证据不被强负化，源记录不改。终止/暂缓门：资格不足或
缺口主要依赖partial/范围歧义，就不进入训练；后续若仍只是分数压缩，
不盲目放大残差或加深线路。实现/只读回放已获用户开始授权，真实训练
仍需完整监督与协议门。未来正式实验交合作者自己的电脑运行。

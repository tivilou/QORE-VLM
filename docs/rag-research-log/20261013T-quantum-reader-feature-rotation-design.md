# 下一候选：问题条件化量子特征旋转，而非分数后残差

- 日期：2026-10-13
- 状态：探索性设计，尚未实现评分模块或训练；没有声称新颖性、收益或量子优势。
- 固定范围：同一 Top-50 中选 Top-5；检索、生成器、答案路径不变。
- 来源：冻结59题228保护对 screen及可达性审计；补充目标几何与原分类头张量回读。

## 先纠正审计的解释范围

168/228保护对超出旧残差的双侧容量，是“该指定正段不能超过该指定负段”的必要界限，不能解释为168个Top-5槽位不可救。一个问题可有多个正段与多个负段；填好有限槽位不要求它们全部两两反转。补充统计：135个唯一漏选直接支持候选中，54个落在乐观Top-5边界容量内，涉及35/59题；其余81个超出该界限。独立调整各候选的分数是乐观松弛，不证明共享模型可学会，也不保证不损害保留段。

旧保护损失要求 `positive <= every immutable-selected`，而pair损失要求 `positive > matched-negative`。99/228对的原始负段排在至少一个保留段前面，两项在原始排序处有方向张力。但分数可以联合移动；允许旧残差盒内独立调整后，pair加零保护惩罚仍有60对可行，不能宣称99对目标数学上绝对矛盾。新实验须分别隔离目标修正和模型修正。

上述检查脚本：`audit_protected_objective_geometry.py`；本地4个边界测试通过，lambeq环境，无安装。原始审计及旧实验不改写。

## 想解决什么

Reader将768维 `[CLS]` 表示交给线性分类头，形成相关分 `b_i = w^T h_i + c`。全159题、7950候选的缓存张量重放成功，最大绝对误差约1.9e-6。分类头 `||w||=0.7360`；输入范数对应的最大绝对中心分数半径中位数约13.01。

我们不知道低估来自编码器丢失证据，还是特征方向与原分类头错配。先验证后一假设：低估段可能仍含可用信息，但对原 `w` 投影不够。旋转特征使支持信息更贴近 `w`，从评分形成处改相对排序。范数上界允许大变化只说明旧0.25×std残差的硬上限消失，不证明所提浅线路能达到任意旋转，更不证明有效。

## 提议结构与公式

1. DPR编码器和原relevance分类头冻结。取最终 `[CLS] h_i`，768维零填充至1024维；保留范数 `r_i`。非零向量幅度编码为 `|h_i> = pad(h_i)/r_i`。
2. 以Reader内部问题和段落池化形成4个有界条件特征 `x_i`。初版用与标注/排名无关的固定seed投影，避免沿用可训练3840→4投影的饱和瓶颈。具体投影尺度在合成工程检查中固定，不能依Silver调参。
3. 一个10-qubit实数、近恒等的条件化线路 `U_theta(x_i)` 旋转该表示。新表示 `h'_i = r_i Re[U_theta(x_i)|h_i>]`，最终 `s_i = pad(w)^T h'_i + c`。线路采用实数门，故Re不丢信息。
4. `theta=0` 时所有门恒等，逐候选恢复原Reader分数；不存在额外logit残差、span加权或按标签选段。量子与经典分支共同生成同一评分路径，按Top-5选段。

这里的量子计算有明确的态编码、可编译门序列和观测：用原分类权重态 `|w>` 做有符号重叠读出，分数为 `||w|| r_i Re< w | U | h_i > + c`。理想硬件可用Hadamard-test估计实重叠。不能用仅有平方重叠的swap-test替代；负分符号必须保留。读出需计辅助qubit、受控态准备、shots及误差。

初版10个数据qubit；2层，每层10个RY和10个环形CRY；40个角度，各角度为 `theta_j0 + sum_a theta_ja x_ia`，共200个可训练参数。CRY零角度恒等；初始200参数全零。低成本对照1层100参数，只做工程trainability/资源诊断，不靠100题择优。环形CRY需记录分解后2Q门数和路由成本；不给未transpile的硬件深度结论。

量子优势目前仅是假设：200个参数描述1024维的结构化条件变换，少于任意满矩阵；必须比较同参数经典结构，不能据此声称量子独有参数优势。态准备和读出可能抵消理想算力收益，10-qubit经典模拟完全可行且允许。

## 控制与目标必须分开

- 冻结Reader Top-k，整个实验统一身份/候选顺序。
- 同参数经典Givens结构，使用相同4条件、相同40角度函数、同范数保留与分类头，200参数。还需无纠缠/条件禁用消融；单纯比大MLP参数少不能证明归因。
- 旧有界头配修正目标，检验收益是否仅由loss修复引起。
- 新旋转头配原目标，检验结构本身与目标修复的交互。量子/经典两臂都作相同2×2设计；不可把两个变化混合后归因量子。

新目标保留资格化正负pair softplus；保护改为“已保留段不能掉出Top-5”，不再要求它永远高于救回正段。对每个保留段计算另外49段中的第5高分 `t_i`，损失为 `ReLU(t_i-s_i)^2`；这只是排序保留约束，不把held段标成无关。边界tie须用实际稳定排序回查，连续loss不能保证硬保护。监督只用冻结59题，禁止标签mask进入线上。

固定同epoch/seed/optimizer，最终checkpoint；初版探索screen计划3epochs、seed20261008，不搜索lr/线路/尺度/检查点。正式实验须另冻结完整预算。上述组合至少Reader+6个训练臂；资源预计缓存head训练远低于重复Reader运行，实测成本未有，不能虚构GPU小时数。

## 门槛和证伪

工程门：真实Reader分数一致、恒等null一致、范数/角度/有符号重叠重放、有效梯度、训练更新及每题score/Top-5完整轨迹、经典同参数控制。首版只作工程实现，不在我们的服务器拟合真实题。

训练诊断：pair反转数、135漏选候选中真实入选数、59题救回槽位、不可变槽位流失、54乐观可达/81超界子群分别报告。pair计数有依赖，不能当228独立样本计算显著性。

100题L0 gate：有用支持段题均差>0且问题级paired bootstrap CI95下限>0；direct题均不降。Silver set仅附加；无Generator运行。量子归因另要求胜过同预算经典和loss-only控制，且有效参数/无纠缠消融可区分。

Stop：破坏null/数据边界/读出符号/轨迹一致性直接终止；若数值健康却训练槽位无救回，则不交新100题screen；若仅loss修复有效则撤回量子机制归因。短预算干净null保持训练家族inconclusive，但不能升级或盲目扩参，不能据此停止量子RAG探索。

L2后续：先独立预冻结完整NQ测试人口与训练监督、强baseline公平对照，再一次完整单seed，追加独立训练seed和未曝光split验证；不把100题做训练。官方全量passage标注不足时先制定可审计的分层支持判定覆盖，不能把100题Silver泛化至全量。L3测试另一数据集；L4比较同预算/结构经典控制、有限shots、态准备/读出资源和纠缠消融。正式预算/资格未闭合，当前仍 `exploratory_only`。
